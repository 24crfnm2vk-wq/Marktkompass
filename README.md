# Marktkompass – öffentliche Oberfläche

Dieses Repository enthält ausschließlich die öffentliche Darstellung des Marktkompass.

Die historischen ACWI-/VIX-Rohdaten und die Berechnungslogik verbleiben im privaten Repository `H1-Pruefstand`.

Die Datei `status.json` enthält nur den aktuell veröffentlichten Ergebnisstand. Sie wird später automatisiert aus dem privaten Projekt aktualisiert.

Stand der initialen Datei: 30.09.2026.
